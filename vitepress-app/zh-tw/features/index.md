# 功能

KIRA 提供豐富的功能來協助您的工作：

## 核心功能

- [聊天](./chat.md) - 與 KIRA 對話
- [記憶](./memory.md) - 自動記住重要資訊
- [任務](./tasks.md) - 任務管理和執行
- [排程](./scheduling.md) - 訊息排程

## 整合功能

- [Email 監控](./email-monitoring.md) - 自動處理郵件任務
- [Confluence](./confluence.md) - Confluence 整合
- [Jira](./jira.md) - Jira 問題管理
- [主動建議](./proactive.md) - 智能建議
