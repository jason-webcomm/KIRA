# 故障排除

如果在使用 KIRA 時遇到問題，請參閱以下常見問題和解決方案：

## 常見問題

### KIRA 無法啟動

**症狀**：點擊「開始」按鈕後 KIRA 沒有回應

**可能的解決方案**：
1. 檢查是否已安裝 Node.js 18 或更高版本
2. 檢查 Slack 權杖是否正確設定
3. 查看伺服器日誌以獲取詳細錯誤資訊

### KIRA 無法回應

**症狀**：在 Slack 中發送訊息後 KIRA 沒有回應

**可能的解決方案**：
1. 檢查網路連線
2. 確認 Slack 應用程式已正確安裝
3. 檢查是否已提及或直接訊息 KIRA
4. 查看伺服器日誌

### 記憶功能無法運作

**症狀**：KIRA 無法記住之前的對話

**可能的解決方案**：
1. 檢查 `FILESYSTEM_BASE_DIR` 設定
2. 確認磁碟空間充足
3. 檢查檔案系統權限

### MCP 整合失敗

**症狀**：MCP 功能（如 GitHub、GitLab 等）無法運作

**可能的解決方案**：
1. 檢查 API 權杖是否正確
2. 確認 MCP 服務已啟用
3. 查看伺服器日誌中的 MCP 錯誤

## 獲取幫助

如果您無法解決問題：

1. 查看伺服器日誌：在 KIRA 應用程式中點擊「日誌」標籤
2. 檢查您的設定：確保所有必要的權杖和設定都正確
3. 聯絡支援：如果您仍然遇到問題，請聯絡您的技術支援團隊
